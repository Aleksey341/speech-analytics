# 🤖 Настройка ИИ интеграций для Speech Analytics

## Обзор возможностей

Система теперь поддерживает интеграцию с ChatGPT 4 и Mistral 3.1 для создания структурированных протоколов встреч. Доступны следующие типы протоколов:

### 📋 Типы протоколов:

1. **Подробный протокол** - детальное резюме с хронологической последовательностью
2. **Управленческое резюме** - лаконичное резюме для руководства
3. **Задачи и поручения** - структурированный список задач с ответственными
4. **Анализ рисков** - выявление рисков и мер митигации
5. **Техническое резюме** - детальный технический анализ
6. **Принятые решения** - анализ всех решений с контекстом
7. **Произвольный анализ** - с вашим собственным промптом

## 🔑 Получение API ключей

### OpenAI ChatGPT 4

1. Перейдите на https://platform.openai.com/
2. Создайте аккаунт или войдите
3. Перейдите в раздел "API Keys"
4. Нажмите "Create new secret key"
5. Скопируйте ключ (он показывается только один раз!)

**Стоимость:** ~$0.03 за 1K токенов для GPT-4

### Mistral AI

1. Перейдите на https://console.mistral.ai/
2. Создайте аккаунт
3. Перейдите в раздел "API Keys"
4. Создайте новый ключ
5. Скопируйте ключ

**Стоимость:** ~$0.015 за 1K токенов для Mistral Large

## ⚙️ Настройка на сервере

### Вариант 1: Переменные окружения (рекомендуется)

Добавьте в ваш `.env` файл:

```bash
# OpenAI API ключ
OPENAI_API_KEY=sk-your-openai-api-key-here

# Mistral AI ключ  
MISTRAL_API_KEY=your-mistral-api-key-here
```

### Вариант 2: Через веб-интерфейс

1. Откройте веб-интерфейс системы
2. Перейдите в раздел настроек (будет добавлен)
3. Введите API ключи в соответствующие поля
4. Выберите предпочитаемого провайдера

### Вариант 3: Через API

```bash
curl -X POST http://localhost:5000/config/ai \
  -H "Content-Type: application/json" \
  -d '{
    "openai_api_key": "sk-your-key",
    "mistral_api_key": "your-key", 
    "preferred_provider": "openai"
  }'
```

## 🚀 Использование

### 1. Анализ аудио/видео

1. Загрузите медиафайл (поддерживаются: MP4, AVI, MOV, MP3, WAV, FLAC и др.)
2. Нажмите "Анализировать" 
3. Дождитесь завершения транскрипции
4. Перейдите на вкладку "Протоколы"

### 2. Создание протоколов

#### Одиночный протокол:
1. Выберите тип протокола из списка
2. Для произвольного анализа введите свой промпт
3. Нажмите "Создать протокол"

#### Все типы протоколов:
1. Нажмите "Все типы протоколов"
2. Система создаст 6 разных типов анализа

### 3. API эндпоинты

```bash
# Создание одного протокола
POST /generate/protocol
{
  "transcript": "текст транскрипции",
  "protocol_type": "detailed",
  "custom_prompt": "опционально"
}

# Создание всех протоколов
POST /generate/all-protocols  
{
  "transcript": "текст транскрипции"
}

# Произвольный анализ
POST /analyze/custom
{
  "transcript": "текст",
  "prompt": "ваш промпт"
}
```

## ⚡ Оптимизация производительности

### Сокращение затрат:
1. **Используйте нужные типы протоколов** - не генерируйте все, если нужен только один
2. **Предварительно очищайте транскрипции** - удаляйте "хм", "э-э", повторы
3. **Выбирайте подходящую модель** - Mistral дешевле OpenAI для простых задач

### Улучшение качества:
1. **Качественная транскрипция** - чем лучше распознавание, тем лучше протоколы
2. **Структурированные встречи** - четкая повестка дня улучшает анализ
3. **Контекстная информация** - добавляйте информацию о теме встречи в промпт

## 🔧 Troubleshooting

### Ошибка "No AI provider configured":
- Проверьте наличие API ключей в переменных окружения
- Убедитесь что ключи валидны
- Перезапустите сервер после добавления ключей

### Медленная генерация протоколов:
- Проверьте интернет соединение
- Ограничьте длину транскрипции (до 10000 токенов)
- Попробуйте другого провайдера

### Низкое качество протоколов:
- Улучшите качество транскрипции
- Используйте более специфичные промпты
- Попробуйте GPT-4 вместо более простых моделей

## 💡 Дополнительные возможности

### Кастомизация промптов:
Вы можете создавать собственные типы протоколов, отредактировав `ai_integration.py`:

```python
PROTOCOL_PROMPTS["my_custom"] = "Ваш промпт здесь..."
```

### Интеграция с CRM:
Протоколы могут автоматически отправляться в CRM системы (см. `Модуль интеграции с внешними сервисами Cload.txt`)

### Batch обработка:
Для обработки множества файлов используйте API в циклах:

```python
for file in audio_files:
    # 1. Анализ аудио
    # 2. Генерация протоколов
    # 3. Сохранение результатов
```
